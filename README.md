# Портфолио переводчика — интерактивный кейс

Интерактивная веб-страница с игровым эпизодом. Игра — **только носитель**:
показать перевод в живом контексте, а не в таблице.
Геймплей намеренно простой. Суть — текст.

## Что показывает проект

Перевод EN → RU и EN → ZH на живых примерах:

- передача смысла, а не слов;
- идиомы, каламбуры, устойчивые выражения;
- регистр (формально / неформально, ты / вы);
- игра слов и то, как с ней работать;
- плюралы, род, числа;
- сохранение интонации и голоса персонажа.

## Что идёт в портфолио

Интерактивная страница с переключателем языков. Заказчик видит
исходный текст и перевод — больше ничего.

## Что остаётся внутренним

В портфолио **не показывается**:

- `locales/ru.mt.json` — черновой машинный перевод, стартовая точка;
- `meta.json` — технические пометки по строкам;
- `export/strings.csv` — рабочий файл.

Это инструменты, а не результат.

## Роли

- **Технический каркас** (игра, i18n, скрипты, хостинг) — разработка.
- **Английский исходник и перевод на RU и ZH** — работа переводчика.

## Запуск

Статика без сборки, но `fetch()` не работает из `file://`. Нужен
локальный сервер:

    python3 -m http.server 8000

Открыть `http://localhost:8000`.

## Языки

- `en` — source, правится напрямую в `locales/en.json`.
- `ru` — целевой, импортируется из CSV.
- `zh-Hans` — целевой, импортируется из CSV.

Переключатель языка — в правом верхнем углу. Выбор сохраняется
в `localStorage`, можно задать через URL: `?lang=ru`.

## URL-параметры

| Параметр | Значение | Что делает |
|---|---|---|
| `lang` | `en` / `ru` / `zh-Hans` | Язык при загрузке |
| `coins` | целое ≥ 0 | Сколько монет в сундуке |
| `debug` | `keys` | Вместо текста — ключи |
| `debug` | `pseudo` | Псевдолокализация (+35 %, диакритика) |
| `debug` | `overflow` | Подсветка строк, вышедших за `max_length` |
| `debug` | комбинируется: `?debug=keys,overflow` | |

### Проверка чисел

    ?coins=1    → 1 монета
    ?coins=2    → 2 монеты
    ?coins=5    → 5 монет
    ?coins=21   → 21 монета
    ?coins=101  → 101 монета

Для китайского — всегда `other`: `N枚金币`.

## Файлы

- `locales/en.json` — английский source. Правится напрямую.
- `locales/ru.json` — русский перевод. Обновляется через `import.js`.
- `locales/zh-Hans.json` — китайский перевод. Обновляется через `import.js`.
- `meta.json` — контекст и технические пометки по строкам.
- `scripts/export.js` — собирает CSV для перевода.
- `scripts/import.js` — импортирует CSV обратно.
- `scripts/scaffold.js` — генерирует пустую локаль с `[TODO: <key>]`.

## Workflow

### 0. Английский source

Правится напрямую в `locales/en.json`. Ключи не менять.

### 1. Экспорт

    node scripts/export.js

Получишь `export/strings.csv` с колонками:

    key, source_en, context, max_length, placeholders,
    translation_ru, translation_zh

Колонки `key`, `source_en`, `context`, `max_length`, `placeholders` —
только для справки. Заполняются `translation_ru` и `translation_zh`.

### 2. Перевод

Открыть CSV в Excel / Google Sheets / CAT.
Заполнить `translation_ru` и `translation_zh`.
Плейсхолдеры `{name}`, `{amount}`, `{item}` должны остаться в переводе.

### 3. Импорт

    node scripts/import.js ru
    node scripts/import.js zh-Hans

`import.js` валидирует:
- плейсхолдеры не потеряны и не добавлены лишние;
- если перевод пуст — подставит `[TODO: <key>]` и предупредит;
- при ошибке в плейсхолдерах файл локали **не перезаписывается**.

### 4. Проверка

Открыть `http://localhost:8000/?lang=ru` и `?lang=zh-Hans`.
Пройти сценарий.

## Что стоит перевести внимательно

- **Каламбур.** `dialogue.merchant.key_pun` — игра слов на «ключ»
  (ключ-предмет / ключ-скрипичный / ключ-родник). Решить, сохранять
  игру слов или жертвовать ради смысла.
- **Идиомы.** `It's a piece of cake`, `Break a leg`. Русский аналог,
  а не буквальный перевод.
- **Регистр.** Стражник — формально, торговец — неформально.
  Где проходит граница в русском.
- **Омонимия.** Английское `Use` в трёх контекстах. `key` — как ключ
  и как клавиша. `open` — глагол и прилагательное.
- **Род.** `He found` / `She found` — в русском меняется и местоимение,
  и форма глагола.
- **Числа.** 1 / 2 / 5 / 21 / 101 монета — формы разные.
- **Интонация.** Голос стражника — сухой и официальный. Голос торговца —
  развязный, с шутками. Сохранить разницу.

## Критерии приёмки

- [ ] EN ↔ RU ↔ ZH переключается без перезагрузки.
- [ ] В `app.js` нет пользовательского текста.
- [ ] `?coins=1|2|5|21|101` даёт корректные формы в RU.
- [ ] ZH не падает на отсутствующих формах множественного числа.
- [ ] `node scripts/import.js ru` падает на битом плейсхолдере.
- [ ] Ни одна реплика не потеряла смысл и интонацию при переводе.

## Добавить новую локаль

1. `node scripts/scaffold.js <lang>`
2. Добавить `{ code, label }` в массив `LOCALES` в `app.js`.
3. Готово.
