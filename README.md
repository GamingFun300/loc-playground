# Интерактивный перевод EN → RU / ZH

Небольшая интерактивная страница с игровым эпизодом, на которой
показаны живые задачи перевода: идиомы, каламбуры, регистр,
омонимия, формы множественного числа.

## Что демонстрирует

- передачу смысла вместо буквального перевода;
- работу с идиомами и устойчивыми выражениями;
- сохранение регистра и голоса персонажа;
- обращение по имени в диалогах и повествовании;
- формы множественного числа в русском (1 / 2 / 5 / 21 монета);
- род и согласование глаголов;
- адаптацию под китайский (классификаторы, отсутствие множественного
  числа).

## О проекте

Оригинальный английский текст, русский и китайский переводы.
Переключение языков — в правом верхнем углу. Весь текст игры
переведён вручную.

Игра — только носитель. Цель проекта — показать перевод
в живом контексте, а не в таблице.
